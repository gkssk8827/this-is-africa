# 블로그 마무리 CTA 스펙

블로그 글 맨 마지막(여운 문장 다음, 해시태그 줄 바로 위)에 들어가는 **고정 마무리 블록**의
내용과 규칙을 정의한다. `agents/writer.md`(문구)와 `agents/image-maker.md`(이미지 선택)가
이 문서를 참고한다.

---

## 1. 마지막 문구 (두 줄)

**1번째 줄 — 전환 문구 (아래 세트에서 매번 하나를 골라 로테이션)**

같은 문구를 매번 반복하지 않도록, 아래 중 하나를 골라 쓴다(직전 발행 글과 겹치지 않는 것 우선):

1. 아프리카 여행은, 아프리카를 가장 잘 아는 사람과 함께 가세요.
2. 20년째 아프리카만 걸어온 여행사, 디스이즈아프리카입니다.
3. 아프리카는 잘 아는 사람과 함께할 때, 비로소 정말 좋아지는 여행이니까요.
4. 같은 곳을 가도, 아는 만큼 보이는 게 아프리카 여행이에요.
5. 여행지가 아니라 여행사를 먼저 골라야 하는 여행, 그게 아프리카예요.

**2번째 줄 — CTA(행동 유도, 고정)**

```
(클릭!) 카카오톡으로 아프리카 전문가와 1:1 상담하기
```

이 줄 전체(또는 이 줄이 걸리는 이미지)에 아래 링크를 건다:

```
http://pf.kakao.com/_likkxl/chat
```

---

## 2. CTA 이미지

- **위치**: 위 두 줄 문구와 함께, 본문 맨 마지막(해시태그 줄 바로 위)에 배치.
- **선택 방식**: `products/cta/` 폴더 안에 있는 이미지 파일 중 **무작위로 1장** 선택한다.
  폴더 안 이미지가 여러 장으로 늘어나도 로직은 그대로 — 매번 그 시점 폴더 안의 파일 목록에서
  랜덤으로 고른다(특정 파일을 고정으로 쓰지 않는다).
- **링크**: 선택된 이미지 자체에 위 카카오톡 채널 링크(`http://pf.kakao.com/_likkxl/chat`)를
  건다 — 이미지를 클릭하면 카카오톡 채팅 상담으로 연결되도록 한다.
- **이미지 자체를 새로 생성하지 않는다**: `products/cta/`에 이미 있는 이미지 중에서만 고른다
  (image-maker가 이 자리를 위해 GPT로 새로 만들지 않음).

---

## 3. 적용 규칙

- 이 마무리 블록은 **카테고리 구분 없이 모든 글에 공통 적용**한다 (product_daily/broadcast/qna/
  book/review/notice/southeast_trend 전부 동일).
- style-guide.md의 "여운 남기는 한 줄 문장"이나 "브랜드 슬로건 클로징"과 완전히 별개는 아니다 —
  이 두 줄이 곧 그 마무리 패턴의 표준화된 형태다. 즉 기존처럼 매번 새 여운 문장을 창작하지 않고,
  위 1번 문구 세트에서 고르는 것으로 대체한다.
- 해시태그 줄은 이 블록 **다음**에 온다 (draft.md 맨 마지막 줄 = 해시태그, 그 바로 위에 이 CTA
  블록이 온다는 뜻).

## 4. 자동화 구현 상태 (2026-07-15)

**이미지에 링크를 거는 자동화가 구현 완료됐다.** `scripts/build_post_json.py`가 본문 이미지 중
파일명이 정확히 `cta.png`인 것을 자동으로 찾아 `CTA_IMAGE_LINK`(이 문서의 카카오톡 채널 링크)를
`post.json`의 해당 이미지 블록에 `"link"` 필드로 붙이고, `scripts/publish.py`가 그 이미지를
삽입한 직후 이미지를 선택 → 속성 툴바의 링크 버튼(`data-name="image-link"`) 클릭 → URL 입력 →
적용까지 자동으로 수행한다(실제 this_africa 계정에서 스크린샷으로 확인 완료). image-maker는
CTA 이미지를 **정확히 `cta.png`라는 파일명으로** 저장해야 이 자동 매칭이 동작한다.
