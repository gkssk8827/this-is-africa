# 트래블 디스이즈아프리카 블로그 SEO·GEO 적용 가이드

원본 "네이버 블로그 SEO & GEO 가이드(2026 상반기)"를 트래블 디스이즈아프리카 블로그(this\_africa)에 맞춰 실무 적용판으로 재정리한 문서입니다. 원본의 공식 미확정 항목("추정")은 그대로 유지하되, 카테고리·키워드·문체는 이 블로그의 실제 운영 방식(TIA NEW / TIA LIVE / TIA 패키지 여행 / 아프리카 여행 정보 / 생생 고객 후기)과 style-guide.md의 브랜드 말투를 기준으로 맞췄습니다.

## 0\. 이 블로그의 위치 요약

- **주제 집중도(C-Rank 관점)**: 아프리카 여행 단일 주제로 512개 글 운영 중 — 이미 강점. 다른 주제(요리·재테크 등) 섞지 말 것.  
- **카테고리별 성격이 다름 → SEO/GEO 적용 방식도 카테고리별로 달라야 함**  
  - TIA 패키지 여행: 시리즈형 여행 후기 (스토리텔링 중심)  
  - TIA LIVE: 방송(세계테마기행, 걸어서세계속으로, 케냐간세끼) 리뷰·공지  
  - TIA NEW / TIA 이야기: 브랜드 소식, FAQ형 정보글  
  - 아프리카 여행 정보: 정보성/실용형 (예방접종, 시즌, 안전 등)  
  - 생생 고객 후기: 경험 기반 후기  
- **문체(style-guide.md)와 SEO/GEO 요구사항이 충돌하는 지점**은 3번 항목에서 절충안 제시.

### 0-1. 2026-07-15 웹 검색 기반 업데이트 확인

아래 항목은 네이버 공식 발표가 아니라 SEO 대행사·마케팅 블로그·커뮤니티 글을 종합한 **업계 추정치**입니다(원본 가이드와 동일한 원칙으로, 참고용으로만 취급). 다만 여러 출처에서 반복적으로 확인되는 방향성이라 이 문서에 반영합니다.

- **키워드 매칭 → "통합탭(피드형 검색)" + "AI 브리핑" 중심으로 전환**: 2026년 들어 네이버 검색이 블로그/카페 탭을 구분하던 방식에서 피드형 통합탭으로 옮겨갔고, AI가 "사용자 의도"에 맞는 글을 직접 골라 요약(AI 브리핑)해 보여주는 비중이 커졌습니다. 즉 "키워드를 몇 번 반복했는가"보다 **"AI가 인용할 만한 구조로 정리됐는가"** 가 더 중요해졌다는 게 다수 출처의 공통된 진단입니다. → 아래 6번 "GEO 우선순위"에 이 관점 반영.
- **D.I.A.+ 알고리즘의 원본성 신호**: 여러 출처가 공통적으로 "AI가 만든 듯한 무색무취한 글"과 "인터넷에서 다운로드한 이미지"를 낮게 평가하고, **직접 촬영/제작한 원본 이미지(추정 5장 이상, 일부 자료는 6~13장)** 와 **영상(네이버 블로그 자체 동영상 에디터 "모먼트" 또는 네이버 클립 삽입)** 을 포함한 글에 가산점을 준다고 언급합니다. 정확한 수치는 비공식 추정치이지만, 방향성은 image-maker.md가 이미 지향하는 "실사 사진 우선, GPT 생성은 보조 수단" 원칙과 일치합니다 — 특히 구글 드라이브의 실제 여행 사진/방송 캡처가 GPT 생성 사진보다 이 신호에 더 유리할 가능성이 높습니다.
- **체류시간(dwell time)**: 일부 출처는 평균 2분 30초~3분 이상의 체류시간을 상위 유지 기준으로 언급합니다(공식 확정 수치 아님). 시리즈물의 이전화/다음화 링크, 표·체크리스트 같은 스캔 가능한 구조는 체류시간에도 도움이 된다는 게 공통 의견입니다.
- **해시태그 개수**: 최신 자료들은 "태그 개수 자체가 상위노출에 직접적 영향을 준다는 근거는 약하고, 태그는 본래 색인 기능이 더 크다"는 쪽에 무게를 둡니다. 이 문서의 기존 "5~10개로 압축" 권장은 유지하되, 근거를 "태그가 SEO를 직접 끌어올려서"가 아니라 "과도한 태그가 저품질/스팸 신호로 읽힐 수 있어서"로 좀 더 정확하게 표현합니다(5번 항목에 반영).

## 2\. 제목 규칙 — 트래블 디스이즈아프리카 적용

- 길이 25~~40자 유지, 지역/미디어명은 반드시 앞쪽 10~~15자 안에.  
- 시리즈물(TIA 패키지 여행)은 "\[지역\] \+ \[화제 포인트\], 아프리카 패키지여행 40일 (N화)" 형식을 계속 쓰되, **화 번호보다 지역/포인트 키워드를 앞으로** 오게 재배열 권장.  
  - 기존: "응고롱고로 거대한 아프리카의 분화구, 아프리카 패키지여행 40일 (5화)"  
  - 개선안: "응고롱고로 분화구 사파리, 세계 최대 칼데라에서 사자 만나는 법 (패키지여행 40일 5화)"  
- TIA LIVE(방송 리뷰)는 방송명+회차+지역을 앞에, 감성 카피는 뒤로.  
  - 기존: "세계테마기행 3부 다시보기, 암피시어터 트래킹, 용의 산맥 드라켄즈버그와 투겔라 폭포를 만나다\!"  
  - 이미 방송명이 앞에 있어 양호. 다만 40자를 넘는 경우가 많아 **모바일 잘림 방지를 위해 핵심 명소 1\~2개로 압축** 권장.  
- 피해야 할 표현은 원본과 동일하되, 브랜드 특성상 특히 주의할 것: "사고율 0%", "최고", "1위" 같은 절대 표현은 **근거 수치(예: "12년간 사고율 0%")를 반드시 함께 명시**해야 D.I.A 신뢰도 검증을 통과하기 쉬움.

## 3\. 문체(style-guide.md)와 SEO/GEO 절충안

기존 브랜드 문체를 깨지 않으면서 GEO 요구사항을 반영하는 방법입니다.

| 상황 | 기존 문체 습관 | SEO/GEO 요구 | 절충안 |
| :---- | :---- | :---- | :---- |
| 도입부 | "안녕하세요, 아프리카 전문 여행사 트래블 디스이즈아프리카입니다 :)" 로 시작 | 인사말 없이 첫 문장에 결론 | **인사말은 1문장으로 짧게 유지하되, 바로 다음 문장에서 핵심 결론(이 글이 무엇에 대한 답인지)을 제시.** 인사말 자체를 없애지 말 것 — 브랜드 톤 유지에 중요함 |
| 소제목 | 2줄 감성 명사구 ("세계 최대 규모의 칼데라, 응고롱고로 분화구") | 질문형 또는 키워드+결론형 | 감성 줄은 유지하되, **그 아래 첫 문장에 스캐너블한 결론 문장을 바로 배치**해서 소제목+첫 문장이 한 세트로 답이 되도록 구성 |
| 문단 길이 | 2\~4문장, 자주 줄바꿈 | 모바일 가독성 2\~4문장 | 그대로 유지 — 이미 SEO 기준과 일치함 |
| 마무리 | 여운 문장 \+ 브랜드 슬로건 | FAQ \+ CTA | 여운 문장은 유지하되, **그 앞에 FAQ 섹션을 삽입**하고 CTA는 기존처럼 "(클릭\!) \~" 형태 유지 |
| 자문자답 | "어…? 우리 책이 여기 왜 있지?" 식 감성적 자문자답 | 질문-답변 구조 선호(GEO) | 감성적 자문자답은 도입부 후킹용으로 유지하고, **정보 전달이 필요한 대목은 별도로 "Q. / A." 형식 FAQ로 분리** |

## 4\. 카테고리별 본문 구조 템플릿

### TIA 패키지 여행 (시리즈 여행기)

1. 인사 1문장 \+ 이번 화 핵심 결론 1문장 (예: "응고롱고로 분화구는 세계 최대 칼데라 지형으로, 짧은 동선에서도 5대 빅게임을 볼 확률이 높은 곳이에요.")  
2. 소제목별 스토리 전개 (기존 방식 유지)  
3. **소제목+본문 요약**: 이날 일정 요약(이동 거리, 소요 시간, 숙소 등급)을 표가 아니라
   작은 소제목(예: "오늘 일정 한눈에 보기") 아래 항목별 문단으로 풀어 쓴다(2026-09-20
   개정 — 아래 "표 대신 소제목+본문" 원칙 참고) — GEO·가독성 모두에 유리  
4. 이전화/다음화 링크 (기존 방식 유지 — 시리즈 체류시간에 유리)  
5. 결론: "이 코스는 \~한 분에게 적합해요" 형태의 대상 명시 문장 추가

### TIA LIVE (방송 리뷰/공지)

1. 방송명+회차+지역을 첫 문장에서 바로 언급하며 "이 방송에서 다룬 곳"을 1\~2문장으로 요약(결론 우선)  
2. 소제목별로 방송 속 장소 소개 (기존 방식 유지)  
3. **마지막에 FAQ 1\~2개 추가**: "이 지역, 트래블 디스이즈아프리카 패키지로도 갈 수 있나요?" 같은 실전 연결 질문  
4. CTA로 마무리 (기존 방식 유지)

### TIA NEW / FAQ형 정보글

- 이미 Q\&A 구조를 쓰고 있어 GEO 친화적 — **형식만 "Q. / A."로 명시적으로 라벨링**하면 AI 인용률이 더 올라감  
- 각 답변에 구체적 수치 유지("12년간 사고율 0%", "최저 5세\~최고 78세 참여") — 이 패턴은 그대로 강점이므로 계속 강화

### 아프리카 여행 정보 (예방접종, 시즌 등)

- 정의 → 조건 → 절차를 항목별로 분리 (현재 혼합 서술되는 경우가 있다면 표가 아니라 소제목+본문
  또는 리스트로 재구성 — 아래 "표 대신 소제목+본문" 원칙 참고)  
- "2026년 6월 기준" 같은 **기준일 명시** 추가 — 예방접종·비자 정보처럼 시점에 따라 바뀌는 내용은 특히 필수

### 생생 고객 후기

- 실제 경험 기반 유지(원칙상 매우 중요 — 허위 후기 절대 금지)  
- 모호한 감상("정말 좋았어요") 대신 구체적 디테일 병기 권장 ("3박4일 동안 하루 평균 도보 이동 1.5km")

## 5\. 이미지·해시태그 — 트래블 디스이즈아프리카 적용

### 이미지 파일명

- `IMG_1234.jpg` → `케냐-마사이마라-사파리-사자.jpg` 처럼 \[지역-명소-상황\] 조합으로 변경  
- 방송 협업 이미지는 `케냐간세끼-마사이마라-사파리.jpg` 처럼 미디어명 포함

### 이미지 개수·원본성 (2026-07-15 추가, 업계 추정치)

- D.I.A.+ 계열 알고리즘이 "인터넷에서 다운로드한 사진"보다 **직접 촬영/제작한 원본 이미지**에
  가산점을 준다는 게 여러 SEO 자료의 공통된 진단입니다(정확한 수치는 비공식이며 자료마다
  5장~13장으로 편차가 있음 — 참고용 목표치로 "글 1개당 최소 5장 이상"을 잠정 기준으로 둡니다).
- 이 원칙은 `agents/image-maker.md`의 기존 우선순위(구글 드라이브 실사진/방송 스크린샷 우선,
  GPT 생성은 보조 수단)와 이미 방향이 같습니다 — 드라이브 실사진·방송 캡처가 이 신호에 더
  유리할 가능성이 높으므로, GPT 생성으로 손쉽게 채우기보다 실사진 확보를 우선하는 현재 방식을
  계속 유지할 근거가 하나 더 생긴 셈입니다.
- 영상(네이버 블로그 자체 숏폼 에디터 "모먼트" 또는 네이버 클립 삽입)도 가산점 요소로
  언급되지만, 이 블로그는 현재 영상 제작 파이프라인이 없으므로 **강제하지 않음** — 방송
  카테고리에서 이미 확보한 영상(broadcast 원본)이 있다면 짧게(15초 내외) 잘라 삽입하는 걸
  향후 검토해볼 수 있다는 정도로만 기록해둡니다.

### 해시태그 세트 (기존 사용 패턴 기반, 5\~10개로 압축 권장)

| 유형 | 예시 |
| :---- | :---- |
| 브랜드형 (매 글 고정) | \#디스이즈아프리카 \#아프리카전문여행사 \#박다애 |
| 지역형 (글마다 선택) | \#케냐여행 \#탄자니아사파리 \#남아공여행 \#나미비아여행 |
| 상품형 | \#아프리카패키지여행 \#아프리카일주 \#사파리투어 \#아프리카허니문 |
| 미디어형 (해당 시) | \#케냐간세끼 \#걸어서세계속으로 \#세계테마기행 |

기존 글들은 한 글에 15~~29개까지 해시태그를 붙이는 경우가 많음 — 원본 가이드 기준(5~~10개)보다 과도할 수 있어 **핵심 태그 위주로 줄이는 것을 권장.** (2026-07-15 확인: 최신 자료들은 "태그 개수가 상위노출에 직접 영향을 준다는 근거는 약하고, 태그는 본래 색인 기능이 더 크다"는 쪽에 무게를 둡니다 — 즉 태그를 줄인다고 순위가 직접 오르는 건 아니지만, 과도한 태그 나열은 여전히 저품질/스팸 신호로 읽힐 위험이 있으므로 압축 권장 자체는 유지합니다.)

## 6\. GEO 우선순위 — 이 블로그에 가장 시급한 4가지

1. **도입부 두괄식화**: 인사말 뒤에 바로 핵심 결론 문장 붙이기 (전체 글에서 가장 쉽게 개선 가능하고 효과가 큰 부분)  
2. **FAQ 섹션 표준화**: 이미 FAQ 형태를 종종 쓰고 있으니, 모든 정보성/방송 리뷰 글 끝에 "Q. / A." 2\~3개를 고정 배치  
3. **수치 기반 결론 문장 강화**: "많은 분들이 만족하셨어요" 류 대신 "70대 고객도 완주한 40일 일정" 처럼 이미 갖고 있는 강점(구체적 수치)을 모든 글에 최소 1회 이상 포함
4. **(2026-07-15 추가, 2026-09-20 개정) 구조화로 "AI 브리핑" 인용 가능성 높이기**: 통합탭 전환 이후 네이버 검색이 키워드 매칭보다 "AI가 답으로 인용할 만큼 구조가 명확한가"를 더 중시한다는 진단이 다수입니다. 소제목(`##`/`###`)을 명확히 나누고, 일정 요약·비교·체크리스트가 필요한 대목은 산문으로 뭉뚱그려 쓰지 말고 **소제목+본문(또는 리스트)으로 바로 정리**하는 습관을 전 카테고리에 일관되게 적용합니다 — 예전에는 이 자리에 마크다운 표를 권장했으나, 표가 모바일/네이버 렌더링에서 오히려 읽기 어렵다는 실사용 피드백(2026-09-20)에 따라 **표 대신 소제목+본문** 형식으로 바꿨습니다. 아래 "표 대신 소제목+본문 원칙" 참고.

### 표 대신 소제목+본문 원칙 (2026-09-20 확정)

- **마크다운 표(`| ... |` 형식)는 더 이상 쓰지 않습니다.** 비교표·일정 요약·체크리스트처럼
  예전에 표로 정리하던 내용도 전부 작은 소제목(`###` 또는 굵은 항목명 한 줄) 아래
  1~3문장 본문으로 풀어 씁니다.
  - 예(개선 전 표 → 개선 후):
    - 개선 전: `| 구분 | 챙기는 요령 | 캐리어(위탁수하물) |` 형태의 표
    - 개선 후:
      ```
      ### 컵라면, 캐리어에 넣어도 될까?

      컵라면은 대부분 캐리어에 넣어갈 수 있어요. 다만 건더기가 큰 육가공품이 든 액상
      스프처럼 반입이 제한되는 품목이 있을 수 있으니 목적지 국가의 식품 반입 규정을
      미리 확인하는 게 안전해요.

      **부피 줄이기**: 컵라면 뚜껑을 반만 뜯어 면과 스프만 빼낸 뒤, 빈 컵 용기는 여러
      개 겹쳐서 챙기면 캐리어 공간을 훨씬 아낄 수 있어요.
      ```
  - 이유: 표는 네이버 블로그·모바일 화면에서 열 너비가 깨지거나 셀 안 줄바꿈이 뭉개져서
    오히려 가독성을 해친다는 피드백을 받았습니다(2026-09-20). 표가 주던 "한눈에 스캔"
    효과는 소제목으로 항목을 나누는 것으로 대체합니다.
  - 정말 짧은 나열(2~3단어짜리 항목을 여러 개 병렬로 보여줘야 할 때)은 표 대신 `-` 불릿
    리스트를 쓰는 것까지는 허용하되, 열이 여러 개인 비교표는 절대 만들지 않습니다.
